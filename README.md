## 📖 Overview

**KnowledgeVault** is a clean, responsive static website for organizing and presenting learning resources and educational content. Built with pure HTML and CSS — no frameworks, no dependencies.

> **Live at** → [https://imoloy.github.io/B13A1](https://imoloy.github.io/B13A1)

---

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| **HTML5** | Semantic page structure |
| **CSS3** | Custom layout, typography, and responsive design |
| **Google Fonts** | Premium typography |

---

## ✨ Core Features

- **Clean Resource Layout** — Organized card-based UI for browsing learning content
- **Fully Responsive** — Mobile-first CSS layout adapts to all screen sizes
- **Fast Loading** — Pure HTML/CSS with no JavaScript overhead
- **Semantic HTML** — Accessible markup with proper heading hierarchy

---

## 📦 Dependencies

No build tools or package manager required. External resources used via CDN:

| Resource | Source |
|---|---|
| Google Fonts | `fonts.googleapis.com` |

## 🚀 Run Locally

1. **Clone the repository**

   ```bash
   git clone https://github.com/iMoloy/B13A1.git
   cd B13A1
   ```

2. **Open in browser**

   ```bash
   open index.html
   ```

   Or serve with a local server:

   ```bash
   npx serve .
   ```
